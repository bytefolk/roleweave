# CXO 岗位参考库

稳定 ID 区分职责；缩写只用于展示。以下是参考职能，不是必须同时招聘的岗位。

| 稳定 ID | 缩写 | 岗位 | 职责 |
| --- | --- | --- | --- |
| chief-executive-officer | CEO | 首席执行官 | 明确公司目标、优先级与资源取舍，对整体结果负责。 |
| chief-operating-officer | COO | 首席运营官 | 将目标转成执行计划，协调流程、进度与交付。 |
| chief-financial-officer | CFO | 首席财务官 | 规划财务资源，分析成本、预算与经营表现。 |
| chief-technology-officer | CTO | 首席技术官 | 制定技术方案，组织研发并检查技术结果。 |
| chief-product-officer | CPO | 首席产品官 | 将用户问题转成产品范围、路线图与验证方法。 |
| chief-marketing-officer | CMO | 首席营销官 | 制定市场定位、品牌与需求获取方案。 |
| chief-human-resources-officer | CHRO | 首席人力资源官 | 规划人才与组织能力，设计招聘、发展和绩效方法。 |
| chief-information-officer | CIO | 首席信息官 | 规划内部 IT、系统集成和企业信息化能力。 |
| chief-data-officer | CDO | 首席数据官 | 管理数据质量、治理和分析价值。 |
| chief-digital-officer | CDO | 首席数字官 | 推动数字渠道、业务模式与运营方式的转型。 |
| chief-ai-officer | CAIO | 首席 AI 官 | 协调 AI 战略、应用落地、治理与价值评估。 |
| chief-information-security-officer | CISO | 首席信息安全官 | 识别信息安全风险，规划防护与事件响应。 |
| chief-design-officer | CDO | 首席设计官 | 规划设计体系，提升产品和服务体验的一致性。 |
| chief-revenue-officer | CRO | 首席收入官 | 协调销售、商业转化与收入增长。 |
| chief-growth-officer | CGO | 首席增长官 | 协调产品、市场和商业职能的增长机会。 |
| chief-commercial-officer | CCO | 首席商务官 | 规划商业战略、渠道与合作关系。 |
| chief-customer-officer | CCO | 首席客户官 | 协调客户成功、产品采用与客户关系。 |
| chief-experience-officer | CXO | 首席体验官 | 协调跨产品、服务与接触点的体验改进。 |
| chief-legal-officer | CLO | 首席法务官 | 整理法律事务、合同与治理问题。 |
| chief-compliance-officer | CCO | 首席合规官 | 规划合规要求、检查与行为规范。 |
| chief-risk-officer | CRO | 首席风险官 | 识别与评估经营、技术和操作风险。 |
| chief-strategy-officer | CSO | 首席战略官 | 研究公司战略、业务组合与战略项目。 |
| chief-procurement-officer | CPO | 首席采购官 | 协调供应商、采购成本、质量和采购策略。 |
| chief-supply-chain-officer | CSCO | 首席供应链官 | 协调供需、物流与供应链韧性。 |
| chief-sustainability-officer | CSO | 首席可持续发展官 | 规划环境与可持续发展目标，整理进展和证据。 |

每条定义包含职责、输入、交付物、协作岗位、执行团队建议、边界和来源。目录默认权限见 catalog.json；实际生效权限取决于场景岗位包和平台配置。

来源见 [sources.json](sources.json)。AI 化职责与团队组合是案例建议；历史来源不表示当前任职。
