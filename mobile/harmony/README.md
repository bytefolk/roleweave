# RoleWeave HarmonyOS

Native ArkTS client. Open the `harmony/` folder in DevEco Studio (API 12 / HarmonyOS 5).

1. Sync the project.
2. Run on a phone or emulator.
3. In 指令, set the RoleWeave host, pair, send a command.

This project does not compile in the Linux sandbox (no DevEco / Harmony SDK).
