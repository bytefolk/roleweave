# 目标与项目管理设计参考

项目管理画板来自 `design/org-workbench-goals-module.pen`；目标工作区沿用 `design/org-workbench-groups-module.pen` 的布局参考。这两个 Pencil 源文件位于外层设计目录，本目录保存本次项目管理画板的导出图，方便审阅。

- [任务看板](project-board.png)：项目列表、任务验收进度、筛选、五种任务状态，以及独立的 Agent 执行记录入口。
- [四周排期](project-schedule.png)：计划范围、单日期任务标记和未排期任务。
- [无任务空态](project-empty.png)：不展示 0/0 进度或空看板列，用拆分、分配、验收三个步骤引导创建任务。

目标工作区增加可筛选的概览、验收标准、执行分支完成比例和会话入口；执行分支完成比例仅作执行证据，目标仍需独立验收。
